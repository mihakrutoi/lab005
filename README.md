# lab005
### 1. Нормализация текста (`normalize.py`)
* **Входные данные:** `"  Один   два  "`
  * **Ожидаемый результат:** Текст: `"Один два"`, Слов: `2`, Длина: `8`, Исходная длина: `14`
  * **Фактический результат:** Совпадает с ожидаемым.
* **Входные данные:** `""` (пустая строка)
  * **Ожидаемый результат:** Текст: `""`, Слов: `0`, Длина: `0`, Исходная длина: `0`
  * **Фактический результат:** Совпадает с ожидаемым.

### 2. Палиндром (`palindrome.py`)
* **Входные данные:** `"А роза упала на лапу Азора"`
  * **Ожидаемый результат:** `Палиндром`
  * **Фактический результат:** Совпадает с ожидаемым.
* **Входные данные:** `"а   "`
  * **Ожидаемый результат:** `Палиндром`
  * **Фактический результат:** Совпадает с ожидаемым.
* **Входные данные:** `"   "` (строка из пробелов)
  * **Ожидаемый результат:** `Нет текста`
  * **Фактический результат:** Совпадает с ожидаемым.
* **Входные данные:** `"Python"`
  * **Ожидаемый результат:** `Не палиндром`
  * **Фактический результат:** Совпадает с ожидаемым.
* **Входные данные:** `"А!"`
  * **Ожидаемый результат:** `Не палиндром` (знаки пунктуации учитываются)
  * **Фактический результат:** Совпадает с ожидаемым.

  * **Фактический результат:** Совпадает с ожидаемым.

### 4. Индивидуальный вариант №12 (`variant.py`)
* **Входные данные:** `"Анна, армия! Я читаю. Книга, край, рама."`
  * **Ожидаемый результат:**
    ```text
    край
    рама
    Количество: 2
    ```
  * **Фактический результат:** Совпадает с ожидаемым.
* **Входные данные:** `""` (пустой ввод)
  * **Ожидаемый результат:** `Нет совпадений и количество 0`
  * **Фактический результат:** Совпадает с ожидаемым.
* **Входные данные:** `"!!!"`
  * **Ожидаемый результат:** `Нет совпадений и количество 0` (знаки очищаются, пустые результаты пропускаются)
  * **Фактический результат:** Совпадает с ожидаемым.
